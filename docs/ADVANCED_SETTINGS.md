# 高级设置与当前功能对应表 · 1.3.2-local

本次按设置窗口、控制器和底层服务逐项核对。高级页没有连接原作者的仓库、下载或更新接口；它使用当前工具的数据目录及本地处理方法。

## 操作对应

| 高级页项目 | 当前处理方式 | 适用范围 |
| --- | --- | --- |
| 切换备份占用与保留上限 | `BackupMaintenanceService.GetStorageSummary` | 统计工具数据目录中的切换备份。已完成的登录回滚备份保留最多 5 份、100 MB、7 天；软件旧版 ZIP 的保留规则另行管理。 |
| 正常关闭等待时间 | 当前账户切换流程 → `CodexProcessService.CloseCodexAsync` | 单窗口“切换当前账户”；独立窗口打开或跳转不使用这个超时。 |
| 超时后允许强制关闭 | 当前账户切换流程中的 `ForceCloseFallback` | 只在需要替换当前登录时使用，且关闭流程核对对应桌面进程。 |
| 切换账号前确认 | 当前账户切换流程中的 `ConfirmBeforeForceClose` | 关闭 Codex 并替换登录之前再次确认。 |
| 打开应用数据文件夹 | 当前 `AppPaths.ApplicationDataDirectory` | 与程序实际使用的数据目录一致，支持复用已有商店打包环境目录。 |
| 打开切换备份文件夹 | 当前 `AppPaths.BackupDirectory` | 登录回滚备份和历史状态备份；不是软件安装包目录。 |
| 清理旧状态备份 | `BackupMaintenanceService.CleanLegacyBackups` | 清理符合旧状态备份命名规则的目录，保留最新两份。 |
| 清理已完成的登录备份 | `BackupMaintenanceService.CleanAllCompleted` | 清理已完成的登录回滚备份，保留正在进行的事务。 |
| 打开日志文件夹 | 当前 `AppPaths.LogDirectory` | 本工具日志。 |
| 重置浮层位置 | 当前控制器 `ResetPosition` → 通用设置应用流程 | 从 1.3.3 起回到“自定义，横向 340、纵向 0”；独立缩放及动画设置保留。最小化球的位置独立，还原后使用重置的账号栏位置。 |
| 重置设置 | 确认后将默认值应用到同一个设置对象 | 立即更新主题、语言、快捷键、自启动、自动显示和额度阈值；账号元数据、认证及对话历史不属于设置文件。 |
| 导出设置 | 注入的 `SettingsService.ExportTo` | 导出当前生效的设置，含已保存快捷键；未保存的快捷键草稿不导出。没有认证或历史文件。 |
| 导入设置 | `SettingsService.ReadImport` → 通用设置保存及应用流程 | 校验 JSON、选项、数值及快捷键；保存到实际数据目录，立即应用并清除旧快捷键草稿。设置窗口保持打开。 |
| 退出应用 | `Application.Current.Shutdown` | 退出浮层工具；不执行账号切换或关闭 Codex 的操作。 |

## 已修复的问题

- 导入、导出写死普通 `%LOCALAPPDATA%` 下的目录，可能与当前实际数据目录不一致。
- 导入只复制文件后关闭窗口，关闭时会用旧内存值再保存，从而覆盖导入结果。
- 重置更换控制器的设置对象，其他窗口仍引用旧对象；自启动、快捷键、自动显示和额度阈值也未走通用应用流程。
- “清理旧版备份”未说明实际是旧状态备份，容易与软件旧版安装包混淆。
- 当前多开模式仍显示“启用账号独立多开”的旧错误提示，已改为当前操作选择提示。

## 网络与来源核对

- 5 小时、每周额度及积分余额：通过已安装的 Codex CLI `app-server --stdio`，调用 `account/rateLimits/read`。程序为每个查询传入对应账号目录。
- 可用重置次数：GET `https://chatgpt.com/backend-api/wham/rate-limit-reset-credits`。它属于 ChatGPT 后台接口，读取失败时显示未知；本工具没有兑换重置的请求。

- 程序源码没有原作者的 GitHub 请求、版本检查或下载地址。

## 验证边界

新增核心测试覆盖自定义数据目录、导出当前值、无效导入不改现有文件、旧配置默认值和完整设置复制。合成 WPF 测试覆盖导入后继续使用及关闭重开、浮窗缩放、设置窗口尺寸、快捷键草稿清除、重置和其他数据文件哈希保持一致。

WPF 测试使用合成文件及模拟保存回调，不运行真实账户切换、自启动注册、全局快捷键注册或线上额度请求。系统注册等接线通过源码核对。此次没有执行用户的备份清理、导入或重置操作。
