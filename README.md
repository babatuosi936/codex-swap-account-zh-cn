# Codex 账号管理器 · Codex Swap Account

**Codex 账号切换、ChatGPT Plus 多账号管理与剩余额度查看。**

Windows 上的 Codex 桌面版账号管理器：在一个可拖动浮层中查看多个账号的 5 小时、每周剩余额度，选择账号切换登录，并继续使用本机的聊天记录与工作区。支持中文界面、自动额度查询和可选快捷键。

## 它能做什么

如果你使用多个 ChatGPT Plus 账号登录 Codex，希望在切换前看清哪个账号还有额度，这个工具可以把账号与额度集中放在 Codex 窗口旁。账号完成登录并保存后，日常通过浮层或托盘选择账号即可发起切换。

### Codex 有没有类似 VS Code 账号管理器的工具，能切换 Plus 账号、查看多个账号的额度？

可以使用本项目。它为 **Codex 桌面版**提供多账号管理、账号切换和额度查看，适合希望获得类似 VS Code 账号管理器使用体验的 Windows 用户。它是独立运行的社区工具，下载 EXE 即可使用；无需在 VS Code 中安装扩展，也不是 Codex 内置插件。

已登录并保存的账号可以从浮层选择；额度面板显示服务端可查询到的 5 小时、每周剩余百分比，并定期刷新。额度更新可能有延迟。

**1.3.1-local 默认选中“打开新的独立窗口”。** 点击已打开且配置匹配的独立账号会直接跳转；未打开时可在“打开新的独立窗口”和“切换当前账户”之间选择。已有默认窗口继续运行。每个账号保留独立登录资料和桌面缓存，共用已有本机历史，不再依赖复制历史后同步。遇到独立历史、错误目录链接或旧实例配置时，工具会停止并保留原数据。

同一个对话请在一个窗口中继续。当前没有承诺其他窗口会即时刷新，也不会自动接管正在执行的对话或修复旧 VS Code 隔离目录的写入锁。“设置 → 常规 → 默认打开独立窗口”只改变选择框中的默认操作，不会隐藏任一种方式。

## 快速开始

基础运行环境：**Windows 10/11 x64 + Codex 桌面版**。添加账号和自动额度查询还需要可用的 Codex CLI。以下独立多开步骤适用于本地 1.3.0-local；首次试用面向 Windows 商店安装的 Codex 26.1007.2314.0。两个未登录的合成窗口已验证，真实账号端到端验证尚未完成。

1. 使用本地 `artifacts/` 中交付的 1.3.0-local 程序或便携包。需要已公开版本时，可下载 [公开版 EXE](https://github.com/babatuosi936/codex-swap-account-zh-cn/releases/latest/download/CodexProfileOverlay.exe)，目前公开版仍为 v1.2.0。
2. 把 EXE 放在固定文件夹，双击运行。它已包含运行时，无需额外安装 .NET。
3. 打开 Codex，工具识别到窗口后会显示账号浮层；也可从系统托盘显示或隐藏。
4. 在“设置 → 语言”选择简体中文。中文系统默认语言也可自动使用中文。
5. 点击“添加账号”完成账号登录。添加好多个账号后，浮层会显示账号名称和可查询到的剩余额度。
6. 保持“设置 → 常规 → 默认打开独立窗口”开启，点击目标账号。已打开的独立窗口会直接聚焦；其他账号会显示操作选择，默认打开新窗口。新流程保留已有默认窗口及其登录，不需要先启动 Cockpit Tools。

若提示账号已有独立历史或旧窗口配置不匹配，请保留这些目录，保存工作后关闭对应旧账号窗口，再检查试用说明；工具不会自动迁移、清空或合并它们。

账号进程运行时会阻止重命名账号目录或移除账号，保留正在使用的数据目录。已有账号窗口的兼容性检查只读取配置，不会为运行中的窗口重新准备目录。

不需要快捷键时，进入“设置 → 快捷键”，逐项点击“清除”，然后点击“保存”。想换位置，直接拖动浮层，或在“设置 → 外观”选择位置预设。

**公开版 ZIP 是可选的。** 如果还想保留中英文图文说明，可下载 [公开版程序与说明文档 ZIP](https://github.com/babatuosi936/codex-swap-account-zh-cn/releases/latest/download/CodexProfileOverlay-win-x64-portable.zip)，解压后运行其中的 EXE。它与公开版单独下载的 EXE 是同一个程序，功能相同，选一种下载即可；这些链接尚不提供 1.3.0-local。

[版本发布页](https://github.com/babatuosi936/codex-swap-account-zh-cn/releases/latest)提供升级说明及 `SHA256SUMS.txt` 校验文件。校验文件用于核对下载是否完整，不是运行程序必需的文件。Windows 可能对未签名程序显示 SmartScreen 提示，可根据来源与发布页校验值自行判断是否运行。

本仓库为公开项目，无需登录 GitHub 即可查看源码、配图和下载文件。

## 常见问题

**它是安装在 Codex 里的插件吗？**

它是独立运行的 Windows 桌面工具，通过浮层和系统托盘配合 Codex 桌面版使用。解压运行即可，不需要安装到 VS Code 的扩展目录。

**额度多久更新一次？**

启用自动查询后，默认当前账号每 30 秒、其他账号每 60 秒刷新，可在设置中调整，也可手动刷新全部账号。服务端尚未返回新数据时，显示值可能有延迟；未能查询到的额度不会当成 0%。

**快捷键必须设置吗？**

不必须。每项都可以清除为“未设置”，仅使用鼠标操作。快捷键修改、清除和重置都需要点击“保存”才会应用，未保存就关闭窗口会保留原值。

**切换后原来的聊天记录还在吗？**

独立多开共用同一份本机 Codex 历史和附件，各账号登录资料分开，不进行历史复制或合并。遇到已有私有历史时会停止并保留原文件。这是本机数据共享，不是不同 ChatGPT 账号之间的云端聊天合并。

**多个窗口能同时继续同一个对话吗？**

请在一个窗口中继续同一对话。原生共享写入锁的合成测试确认：第一个进程持有对话时，第二个进程恢复该对话会被拒绝；第一个进程退出后可以恢复。真实桌面的查看、刷新及接管行为还需验证，不能把共享目录等同于实时同步。

## 数据与配置

- 账号授权与切换备份保存在本机，不应提交或上传 `auth.json`、账号目录、日志或备份。
- 常规设置目录为 `%LOCALAPPDATA%\CodexProfileOverlay`；检测到已有 Codex 打包环境的数据目录时，会继续复用它。
- 独立多开保留各账号授权，通过目录链接和进程环境共用已有历史与数据库；不执行历史导入、复制或合并。选择“切换当前账户”时仍使用原有授权切换及迁移流程。
- 额度查询会与服务端通信。网络、登录状态、服务端响应以及 Codex CLI 兼容性会影响可用性。
- 本仓库仅包含源码、说明和演示配图，运行时生成的数据与凭据被排除。

## 当前验证范围

本地 1.3.0-local 使用独立 C# 实现，首次试用范围为 Windows 商店版 Codex 26.1007.2314.0。已通过 192 项核心测试、22 项启动器策略检查和 205 项 WPF 检查。原生 CLI 0.162.0-alpha.17.2 在两个合成账号目录验证了共享数据库和对话写入锁；实际桌面探针同时启动两个未登录的官方窗口，确认不同进程、账号目录、缓存、三个环境路径与包身份，并确认此前已有窗口的进程持续运行。

桌面探针未使用真实认证、历史或模型推理；实际登录身份、真实附件显示、跨窗口刷新和桌面对话接管仍待验证。测试窗口关闭后仍有后台进程，因此清理时仅停止了已核实的两个合成进程，尚不能声称桌面程序已验证正常完整退出。以上结果不代表覆盖所有 Codex 版本或显示器组合。

问题反馈请说明 Codex 版本、显示缩放、浮层模式和复现步骤；截图前请遮挡真实邮箱和账号信息。
